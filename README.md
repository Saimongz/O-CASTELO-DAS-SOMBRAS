# O-CASTELO-DAS-SOMBRAS
É um jogo de texto onde o jogador precisa sobreviver a salas com eventos aleatórios, enfrentar monstros, coletar elixires e manter sua vida. No final, ele encara o Mago das Charadas, que faz três enigmas escolhidos aleatoriamente. Acertar todas garante a fuga do castelo; errar significa recomeçar.
